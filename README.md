# KAYÉA — Boutique en ligne gratuite

Version 1 : boutique statique mobile-first avec :
- produit Box Boucles Tropicales à 49,90 €
- panier
- bouton de paiement Stripe
- bouton WhatsApp
- lien Instagram
- pages Mentions légales / CGV / Confidentialité

## À faire avant publication
1. Créer un compte Stripe et sélectionner France comme pays pour une activité basée en Martinique.
2. Créer un Payment Link Stripe pour la Box Boucles Tropicales.
3. Ouvrir `config.js` et remplacer `COLLE_ICI_TON_LIEN_STRIPE` par le lien Stripe.
4. Remplacer `59600000000` par le vrai numéro WhatsApp KAYÉA dans `config.js` et `index.html`.
5. Remplacer le compte Instagram par le vrai compte.
6. Compléter les mentions légales, CGV et confidentialité avec les informations réelles de l'entreprise.
7. Publier gratuitement via GitHub Pages.

## Publication GitHub Pages
Créer un dépôt public sur GitHub Free, déposer les fichiers, puis Settings > Pages > Deploy from a branch > main > /root.
Le site sera accessible sur une adresse github.io. Un domaine personnalisé pourra être ajouté plus tard.
